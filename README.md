# 黑流树海粥集杯#1 计分器

《明日方舟》集成战略赛事「**黑流树海粥集杯#1**」的 **纯前端**计分器 + 实时排名榜单。

**零后端、零依赖、零构建** —— 下载即用，或直接开网页。

> 🔗 在线使用：**https://<你的GitHub用户名>.github.io/arknights-blackflow-counter/**
>
> （部署好 GitHub Pages 之后，把上面 `<>` 里的用户名换成你自己的）

---

## 这个项目是什么

| 页面 | 文件 | 作用 |
|---|---|---|
| **计分器** | `index.html` | 9 个计分面板（选手 / 临时招募 / 通关时长 / 关卡通关 / 源石锭 / 违规扣分 / 击杀特殊敌人 / 藏品与路线 / 商店）+ 顶部「赛事规则」面板 + 底栏总分结算；支持 **txt 存档导出 / 导入** |
| **实时排名榜单** | `ranking.html` | 初赛 / 决赛**双榜单**各自独立存档；决赛支持添加队伍、按队合计分自动编号（前三名戴金银铜）、拖拽调整分组、双击队名就地改名、队头显示全队「已使用 / 剩余」源石锭；同样支持 **榜单 txt 导出 / 导入** |

两个页面复用同一份 `css/style.css`，观感一致。计分器里改完数字，切到榜单页刷新就能看到。

**特色**：3 / 2 / 1 栏自适应布局（按窗口宽度自动分栏并配平底边）、勾选项互斥与联动、
源石锭余额可在面板标题的齿轮弹框里改（初赛 / 决赛两档）、黑诞三条可叠加、
结算分按「（结算分 − 零件数量 × 5）÷ 2」计算。

## ⚠️ 数据存在哪？（每个人只看得见自己的）

**本项目没有服务端、没有数据库、不做任何数据上报。**
所有数据都存在**你自己这台设备的这个浏览器**里（`localStorage`）：

| `localStorage` 键 | 存的是什么 |
|---|---|
| `hlsh_zhoujibei_counter_v1` | 计分器存档（含源石锭余额设置） |
| `hlsh_zhoujibei_ranking_v1` | 初赛榜单 |
| `hlsh_zhoujibei_ranking_final_v1` | 决赛榜单 |
| `hlsh_zhoujibei_rules_v1` | 赛事规则文本 |

由此推出的几件事 —— **都是刻意设计，不是 bug**：

- **别人看不到你的数据。** 别人打开同一个链接，用的是**他自己浏览器**的存储空间；新访客看到的是空榜单
  （`js/ranking-data.js` 里只有一个空数组）。你录的选手名、分数、队伍，一个字都不会离开你的电脑。
- **「实时」指的是你自己机器上的实时。** 计分器与榜单页同源，所以计分器里改完、榜单页刷新（或另开一个标签页）
  就能读到；榜单页另外监听了 `storage` 事件 —— 在另一个标签页改了决赛初始余额，榜单页会**自动重算剩余源石锭**。
- **跨设备 / 跨浏览器不同步。** 换电脑、换浏览器、清缓存、开无痕模式 → 数据不跟随。这是本地存储的天性。
- **本地打开与在线打开是两套互不相通的数据。** `file:///.../index.html` 和 `https://....github.io/...`
  是两个不同的存储空间，各有各的存档。想两边都留一份，就在两边各导入一次 txt。
- ⚠️ 同一个 GitHub 账号下的**所有项目页共用** `https://<用户名>.github.io` 这一个存储空间。
  本项目的键名都带 `hlsh_zhoujibei_` 前缀，不会和别人的项目撞车。但如果将来给这个站绑定**自定义域名**，
  存储空间会换成新的 → 旧数据看起来「消失」了（其实还留在原域名下）。**绑域名之前先用 txt 导出备份。**
- **想多人共用一份榜单 / 多设备自动同步？** 那必须另外加服务端，本项目刻意没有做。

### 怎么把数据搬走或交给别人

两个页面都有 **导出 txt**（榜单页的两个按钮钉在操作区最左 / 最右）。存档格式是
「**上半给人看 + 结尾一行 `DATA:{...}` 给机器读**」，导入时只读那一行，所以你可以放心地打开来看。
计分器的存档可以传给队友，也可以直接在另一台设备导入。

```bash
node _test/e2e-ranking.js   # 榜单页端到端：真浏览器几何实测 + 截图
node _test/e2e-counter.js   # 计分器首页端到端
```

## 发布到 GitHub Pages（维护者）

1. 把代码推到 GitHub（默认分支 `main`）。
2. 仓库 **Settings → Pages → Build and deployment**，Source 选 **Deploy from a branch**，
   分支选 **`main`**、目录选 **`/ (root)`**，保存。
3. 等一两分钟，访问 `https://<你的GitHub用户名>.github.io/arknights-blackflow-counter/`。

因为站内所有资源引用都是**相对路径**（`css/…`、`js/…`、`img/…`），放在子路径下不需要任何额外配置。

## 与原站/常规规则的差异（刻意的）

本项目参考了 [黑流树海仙术杯#9 计分器](https://qimstar.github.io/blackflowcounter/)，并按本赛事规则做了如下调整：

1. 通关时长 **≤2:00 档 +60**（原站从 ≤2:30 +50 起）
2. **删掉**「板藤」估价上涨 −40
3. 「额外招募六星干员」**−60**（原站 −100）
4. **新增**「永无安宁 +250」「普通·合伙人会议 +50」
5. 藏品与路线的加分项按本赛事规则重写
6. 通关得分 = **（结算分 − 零件数量 × 5）÷ 2**（原站 ×7.5）
7. 源石锭余额两档可配：初赛 60、决赛 120（面板标题右侧齿轮可改）
8. 结算面板**去掉了原站的「个人 / 团队」切换**，改用「团队分按模式拆」：初赛不拆、决赛拆
9. **黑诞三条（100 / 120 / 140）不再互斥**，可以叠加
